
# RAJ HOUSE - Kids Clothing Store

Raj House is a modern e-commerce website designed for children's clothing. It provides a simple and user-friendly shopping experience.

## Features

- Modern and responsive homepage
- Kids clothing product catalogue
- Product category filtering
- Shopping cart management
- Quantity updates and product removal
- Checkout form
- Cash on Delivery demo option
- Customer registration and login
- My Account page
- Order history

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Project Structure

- index.html - Homepage
- cart.html - Shopping cart
- checkout.html - Checkout page
- login.html - Customer login
- register.html - Customer registration
- account.html - Customer account and order history
- css/style.css - Website styling
- js/ - JavaScript functionality

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Browse products and test the shopping features.

## Important Note

This project is developed for educational purposes.
It uses browser LocalStorage for demonstration.
Online payments are not processed, and authentication
is not connected to a secure backend server.
